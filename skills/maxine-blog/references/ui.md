# 红白博客 UI 规范

## 视觉方向与色彩

小红书感的红白配色、圆角卡片和分类标签，结合长文阅读的留白与克制排版。以下为博客自定义色值，不是小红书官方品牌规范。新增或改造页面遵循此方向，不继续扩展旧的米白深绿主题。

| Token | 色值 | 用途 |
| --- | --- | --- |
| --color-brand | #FF2442 | 品牌点缀、选中标记、主要操作的视觉强调 |
| --color-brand-strong | #D91535 | 正文链接、白字按钮的较深底色 |
| --color-background | #FAFAFA | 全站背景 |
| --color-surface | #FFFFFF | 卡片、导航、文章区域 |
| --color-text | #202124 | 标题、正文 |
| --color-text-muted | #666666 | 摘要、日期、辅助信息 |
| --color-border | #E8E8E8 | 分隔线、卡片边框 |
| --color-tint | #FFF1F3 | 选中分类、引用、轻提示 |

实现时统一定义 CSS 自定义属性或项目已有的等价 token，避免每篇文章复制色值和样式。白色、浅灰占主要面积，红色集中在关键位置。

正文链接使用深红并加下划线。小字号白字按钮优先使用深红底；验证实际状态的颜色对比度，普通文字至少 4.5:1。浅灰装饰线不承担唯一的交互边界。选中、错误和焦点状态不能只依赖颜色。

## 字体、尺寸与空间

中文采用 PingFang SC、Microsoft YaHei 等系统无衬线字体，英文采用系统无衬线字体；不要求加载额外字体。标题偏粗，正文保持正常字重。

| 项目 | 桌面端 | 手机端 |
| --- | --- | --- |
| 文章标题 | 36–40px | 28–30px |
| 正文 | 18px | 17px |
| 二级标题 | 26px | 23px |
| 辅助信息 | 14px | 14px |
| 中文行高 | 1.85 | 1.85 |
| 英文行高 | 1.75 | 1.75 |
| 正文宽度 | 最大约 720px | 两侧各 20px 留白 |
| 页面宽度 | 最大约 1120px | 自适应 |

- 间距体系以 8px 为基础：8、16、24、32、48、64。
- 卡片圆角 16px，按钮 12px，分类标签胶囊形。
- 使用 1px 浅灰边框，默认少用阴影。
- 图片容器统一圆角；列表封面比例为 3:2，正文图片保留适合内容的比例，避免裁掉截图信息。
- 悬停和焦点变化约 150–200ms，支持减少动态效果偏好。

## 页面与组件

### 导航与首页

导航：站名与红色小圆点、首页／博客／关于、中文／EN。项目入口在有真实内容后加入。品牌名采用现有配置，用户确认改名时可用 Maxine’s Notes。

首页顺序：简短个人介绍 → 浏览文章与关于入口 → 2–3 篇精选 → 最近约 5 篇文章 → 已有内容的主题入口 → GitHub／RSS 页脚。

个人介绍不占满首屏。精选采用桌面双列卡片，最新文章采用紧凑列表；内容不足时只显示最新文章，避免两个区域重复。

### 博客目录

- 标题与简介下提供「全部／工具与工作流／学习与实践／随笔与观察」分类筛选，只展示有内容的分类。
- 当前分类用浅粉底、深红文字与明确选中语义；其他分类白底灰边。
- 桌面两列顺序网格，手机单列。分类在窄屏自然换行。
- 卡片包含可选封面、标题、两行左右摘要、分类、日期，可显示可信的阅读时间。
- 无封面时使用文字卡片，避免为填充卡片生成无关图片。卡片内避免嵌套交互链接。
- 文章增多后再增加搜索与分页，不预先铺设无内容的功能。

### 文章页

顺序：面包屑 → 标题 → 摘要 → 发布／更新日期与阅读时间 → 对应语言入口 → 目录 → 正文 → 相关文章。

- 长文目录桌面可置于右侧；手机置于正文前折叠区域。短文不强加目录。
- 引用为浅粉背景与红色左边线，代码块浅灰底，表格使用清晰表头和细线。
- 表格和代码块局部横向滚动，避免整页水平溢出。
- 标题自然换行，文章页不截断；英文长词和 URL 应合理断行。
- 相关文章优先当前语言，没有相关文章时隐藏该区域。

### 关于页与状态

关于页使用同一字体、宽度和色彩，呈现用户真实背景、关注方向与已提供的联系渠道。404、空分类、搜索无结果、缺少译文都提供对应语言的清晰提示与可用返回入口，不使用占位内容冒充成品。

## 双语、移动端与可访问性

- 两种语言复用布局；导航、按钮和卡片为较长英文留出空间，不依赖固定文字宽度。
- 全局语言入口显示中文／EN，文章内明确指向译文。缺少译文采用轻提示和单独的语言博客入口。
- 触控区域至少 44px，键盘焦点可见；链接、按钮和折叠目录使用合适的语义元素。
- 手机导航应完整可达；需要折叠菜单时，检查展开／关闭和键盘操作。
- 实现后至少检查手机与桌面，以及长中文标题、长英文标题、无封面和无译文状态。仅报告实际完成的视觉验证。
